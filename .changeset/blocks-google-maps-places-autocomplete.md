feat(blocks-google-maps): add a `PlacesAutocomplete` input block. The block searches the Google Places Autocomplete Data API from inside a `GoogleMapsScript`, ideally one that loads the places library with `libraries: [places]` (otherwise the library is imported on demand). Its value is an object: selecting a suggestion fetches the place fields listed in `fetchFields`, renames them through `resultMapping` (dotted paths nest) and writes them to the value, while typing writes the free text to `labelField`, so a form still holds a usable address when no suggestion is picked. Typing, selecting or clearing removes the fields the previous place wrote, so typed text never keeps another place's coordinates, while sibling keys written by other blocks are preserved. Suggestion requests are debounced (`debounce`, default 250 ms) and share a session token per search. Suggestions can be restricted or biased through `requestOptions`, antd design tokens can be overridden through `theme`, and the block emits `onPlaceChanged` (with the mapped place), `onChange` (with the new value), `onError`, `onSearch`, `onClear`, `onBlur` and `onFocus`. Outside a `GoogleMapsScript`, or when the places library cannot be loaded, it is a plain text input.
