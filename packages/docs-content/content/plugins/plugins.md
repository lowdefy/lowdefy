# Plugins

Everything in Lowdefy is a plugin — every block, operator, action, and connection
is an npm package, and your app can install more. A browsable catalog of official
and community plugins is coming; until then, the
[community plugins repository](https://github.com/lowdefy/community-plugins) lists
what the community has published.
