# Schema Reference

Every Lowdefy app is one config object, assembled from your YAML files at build time.
The schema material lives with the concept that owns it — this hub points to each area.

The lowdefy.yaml root object, pages, and how config is assembled.

The block object — id, type, properties, layout, style, events, and slots.

Connections, requests, and payloads.

Providers, adapters, callbacks, and protected pages.
