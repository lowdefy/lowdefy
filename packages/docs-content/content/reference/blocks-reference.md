# Blocks

Blocks are the visual building parts of every page. Browse by what you are building — the sidebar groups the same blocks by technical type (Input / Display / Container / List).

Forms

Capture input with validated form controls.

Data display

Tables, charts, and stats.

Layout

Arrange content on the page.

Feedback

Alerts, modals, and loading states.

Navigation

Menus, steps, and wayfinding.

Media

Images, maps, and files.

Text

Titles, prose, and rich content.

AI

Agent chat interfaces, documented under Learn › AI Agents.
