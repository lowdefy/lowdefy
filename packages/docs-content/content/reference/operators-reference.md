# Operators

Operators are functions written directly in config — they evaluate wherever they appear. All 70 operators, grouped by what they do. See [Operators](/operators) for how evaluation works.

Logic & control

Branch, compare, and combine conditions.

State & context

Read page, user, and app context.

Requests & APIs

Read request responses and API results.

Build & config

Compose config at build time.

App & i18n

App metadata, menus, theme, and translations.

Data manipulation

Get, shape, and query data structures.

Math

Arithmetic and number utilities.

String

Transform and match strings.

Date & time

Create and format dates.

Programming

Escape hatches into JavaScript and expressions.

Format & encode

Serialize, encode, and hash values.
