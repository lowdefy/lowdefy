# Recipes

Recipes are end-to-end compositions — complete, copyable examples that show how
blocks, operators, actions, and connections work together to solve a real problem.

The first recipes are on their way:

- Login flow with protected pages
- CRUD table with edit modal
- File upload with live preview
- Multi-step form with validation
- Dashboard with filters, KPIs, and a chart

Until they land, the [tutorial](/tutorial-start) builds a complete app step by step,
and the [example repositories](https://github.com/lowdefy?q=example) on GitHub cover
common patterns like CRUD, surveys, and authentication.
