# Lowdefy Operators Cron

Cron Lowdefy operators.

The `_cron` operator works with cron expressions on both the client and the server:

- `_cron.next` - the next occurrence of a cron expression.
- `_cron.previous` - the previous occurrence of a cron expression.
- `_cron.describe` - a human readable description of a cron expression.
- `_cron.validate` - test if a cron expression is valid.
- `_cron.fields` - the parsed fields of a cron expression.

See the [`_cron` documentation](https://docs.lowdefy.com/_cron) for details.
